# 同步官方 v0.2.24

同步日期：2026-11-20。基于本项目 `6d083362c`，合并官方发布 `v0.2.24`（`5c2982a81`）及随后更新版本号的 `328db26f4`。

## 更新内容

- 合并重复请求字段校验、模型白名单绕过修复，以及检索接口 403 误停用 OpenAI OAuth 账号的修复。
- 合并 OpenAI 超时切换、OAuth 凭据轮换保护、Antigravity 429 处理和额度查询修复。
- 合并 Grok 搜索成功次数计费、五张图片编辑、协议转换与请求处理性能改进。
- 新增 Exa 搜索提供方、Claude 窗口费用估算、模型 ID 复制和手动刷新 Token 提示。

## 二开功能与兼容性

合并没有文本冲突。复核双方修改的重叠文件后，保留原有 Grok 短暂故障有限重试、不写入账号级临时禁用、旧临时隔离恢复，以及“永不临时禁用”开关。官方新增的凭据并发更新保护和调度逻辑同时保留。

独立的监控 V3、降智检测、实时指标、支付定制及其迁移文件均未被本轮合并改动。前端账号列表同时保留二开的实时指标和官方用量刷新改进。

相对本项目 v0.2.23 没有新增或修改数据库迁移文件，也没有新增表或字段。已有二开迁移继续保留。

官方兼容性变化：请求体、WebSocket 帧或 multipart 表单中的重复字段会被拒绝，包括值相同的重复字段；使用这类非标准请求的客户端需要修正。正常 SDK 无需调整。

## 服务器更新

当前已知源码路径为 `/root/xingxing-sub2api`，实际生产 Compose 配置位于 `/root/hakimi-sub2api/deploy`，项目名 `deploy`，应用镜像 `xingxing-sub2api:local`。

服务器需要另行拉取本仓库、构建镜像，确认版本后再安排备份和切换。保留原数据库、Redis、配置和数据卷，仅重建应用服务。不要直接运行源码目录中默认使用官方镜像的 Compose，也不要使用 `docker compose down -v`。

本轮仅同步代码，不操作服务器容器或数据。若此前未部署 v0.2.23，则从 v0.2.22 升级仍会包含 v0.2.23 的数据库字段迁移，不能将本轮“无新增迁移”理解为所有旧版本都没有迁移。
